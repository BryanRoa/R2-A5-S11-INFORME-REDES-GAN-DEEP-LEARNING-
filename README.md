# 🧠 Práctica de Redes Generativas Antagónicas (GAN) — MNIST

Repositorio académico que documenta la implementación de una **Deep Convolutional GAN (DCGAN)** para la generación de dígitos manuscritos del dataset MNIST, junto con el informe en formato APA 7 y el notebook que lo genera automáticamente.

---

## 📖 Descripción

Este proyecto tiene como objetivo **comprender y aplicar los fundamentos de las Redes Generativas Antagónicas (GAN)** mediante un caso práctico: el entrenamiento de una DCGAN para generar imágenes sintéticas de dígitos manuscritos a partir del dataset MNIST.

El trabajo se compone de dos entregables principales:

1. **Notebook de entrenamiento** (`.ipynb`) — implementa la GAN desde cero con TensorFlow/Keras y entrena el modelo en Google Colab.
2. **Informe en Word** (`.docx`) — documento académico con formato APA 7 que recoge los conceptos clave, la descripción de la práctica, los resultados, el análisis y las conclusiones.
---

## ✨ Características del proyecto

- ✅ Implementación completa de una DCGAN con TensorFlow 2.21.0.
- ✅ Entrenamiento en GPU NVIDIA T4 (Google Colab) en ~2.3 minutos.

---
